# Playfair Cipher Code

[`Playfair-Cipher.py`](Playfair-Cipher.py) is the original lecture fragment.
It contains a sample 5×5 letter matrix and a `find_position` helper, but does
not implement complete encryption or decryption. Its existing demonstration
prints the position of `h`.

No separate original encryption, decryption, or test files were found. See
the [Lecture 02 source scan](../../Lectures/Lec-02/source/Lec-02.pdf) and
[algorithm notes](../../Algorithms/Playfair/notes.md) for course context.
