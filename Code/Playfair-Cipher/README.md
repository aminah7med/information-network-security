# Playfair Cipher Code

[`Playfair-Cipher.py`](Playfair-Cipher.py) is the original lecture script. It
builds a keyed 5×5 matrix, prepares plaintext into digraphs, and encrypts
digraphs. The script does not implement decryption.

The earlier alternate encryption script is retained as
[`Playfair-Cipher-supplementary.py`](Playfair-Cipher-supplementary.py).
No test file is currently provided. See the [Lecture 02 source
scan](../../Lectures/Lec-02/source/Lec-02.pdf) and
[algorithm notes](../../Algorithms/Playfair/notes.md) for course context.
