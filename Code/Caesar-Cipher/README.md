# Caesar Cipher Code

This directory contains the original interactive [Caesar encryption
script](caesar_encryption.py) and [console checks](tests.py). The script
accepts uppercase or lowercase letters, converts the message to uppercase,
and preserves non-letter characters. No original lecture decryption script
was found, so a supplementary decryption implementation is not included.
